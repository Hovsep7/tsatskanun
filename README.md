# Ծածկանուն

A Codenames-style word game for the Homenetmen Jerusalem scouts, in Western Armenian and English.

- Open the page on a laptop connected to the projector (press **F** for fullscreen).
- Spymasters scan the QR code in the lobby to see the key on their phones.
